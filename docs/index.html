JavaScript는 어떻게
웹 문서를 바꾸는가

HTML이 문서 객체가 되는 과정, JavaScript가 값을 기억하고 실행하는 방식, 사용자 입력이 화면 변화로 이어지는 원리를 차례로 설명합니다.

먼저, 화면 뒤에 있는 세 가지를 구분합니다

웹페이지에 “안녕하세요”라는 글자가 보인다고 해봅시다. 그 글자는 HTML 파일에 적힌 문자열일 수도 있고, 페이지를 연 다음 JavaScript가 새로 넣은 내용일 수도 있습니다. 같은 모습이어도 내용이 만들어진 과정은 다릅니다. 이 과정을 이해하려면 파일에 적힌 문서, 브라우저가 기억하는 문서, 실제로 그려진 화면을 구분해야 합니다.

HTML은 문서의 구조와 의미를 적는 언어입니다. <p>안녕하세요</p>는 한 문단을 선언합니다. 브라우저는 이 문자열을 읽고 p 요소와 그 안의 텍스트를 나타내는 객체들을 만듭니다. 이렇게 연결한 문서 객체의 구조를 DOM(Document Object Model)이라고 부릅니다. DOM은 웹페이지의 문서를 프로그램에서 다룰 수 있도록 표현한 모델입니다.

브라우저는 DOM의 요소와 CSS 규칙을 바탕으로 위치, 크기, 색 등을 계산해 화면을 그립니다. 따라서 DOM은 화면의 픽셀 자체가 아닙니다. 화면을 구성하는 데 사용하는 문서의 상태이며, JavaScript가 읽거나 바꿀 수 있는 대상입니다. DOM을 바꿔도 원래 디스크에 있던 HTML 파일의 내용까지 수정되는 것은 아닙니다.

JavaScript와 DOM은 같은 것이 아닙니다

JavaScript는 계산과 실행 규칙을 표현하는 프로그래밍 언어입니다. 변수에 값을 담고, 함수를 호출하고, 조건에 따라 다른 작업을 실행하는 규칙이 언어에 속합니다. 숫자를 더하는 데 문서는 필요하지 않습니다. 이 언어를 실행하는 엔진은 브라우저 안에도 있고, 웹페이지가 없는 다른 실행 환경에도 있습니다.

브라우저는 JavaScript가 웹 문서를 다룰 수 있도록 document 같은 객체와 문서 조작 기능을 제공합니다. 프로그램에서 기능을 사용할 수 있도록 공개한 약속을 API라고 합니다. DOM API에는 요소를 찾거나, 텍스트를 바꾸거나, 자식 요소를 추가하는 기능이 들어 있습니다. JavaScript 문법으로 이 기능을 호출하는 것이 DOM 프로그래밍입니다.

바닐라 JavaScript는 별도의 언어나 패키지 이름이 아닙니다. 여기서는 프레임워크 없이 JavaScript 언어와 브라우저의 기본 API를 사용하는 방식을 뜻합니다. HTML 파일 하나에 CSS와 JavaScript를 함께 넣을 수 있지만, 같은 파일 안에 있다고 세 언어의 역할이 합쳐지는 것은 아닙니다.

세 줄의 코드를 문장으로 읽어봅니다

<p id="greeting">처음 문구</p>

브라우저가 위 HTML을 읽은 뒤, 다음 JavaScript를 실행한다고 가정합니다.

let message = "안녕하세요";
const paragraph = document.querySelector("#greeting");
paragraph.textContent = message;
  1. 첫 줄은 값을 준비합니다. 문자열 “안녕하세요”를 message라는 이름으로 사용할 수 있게 합니다. 이 줄만으로는 문서를 바꾸지 않습니다.
  2. 둘째 줄은 문서 속 객체를 찾습니다. querySelector는 조건에 맞는 첫 요소를 반환하는 DOM 메서드입니다. 메서드는 객체를 통해 호출하는 함수입니다. #greeting은 id가 greeting인 요소를 찾는 CSS 선택자이며, paragraph에는 HTML 문자열의 복사본이 아니라 그 요소를 가리키는 참조가 들어갑니다.
  3. 셋째 줄은 그 객체의 내용을 바꿉니다. textContent는 요소의 텍스트 내용을 다루는 속성입니다. 값을 대입하면 DOM이 변경되고 브라우저가 이후 화면 갱신에 반영합니다.

이제 message에 다른 값을 대입한다고 paragraph의 내용까지 저절로 다시 계산되는 것은 아닙니다. JavaScript는 실행된 명령이 만든 결과를 유지합니다. 새 값을 화면에 쓰려면 문서를 변경하는 명령을 다시 실행해야 합니다. 뒤의 상태와 화면 장에서는 이 연결을 왜 함수로 모으는지 설명합니다.

이 책이 이어지는 순서

처음 두 장은 코드를 실행하는 쪽인 JavaScript와 조작할 대상인 DOM을 각각 설명합니다. 다음 장들은 문서를 바꾸는 방법, 사용자 행동을 전달받는 방법, 그 변화의 기준이 되는 상태를 다룹니다. 브라우저의 실행 순서와 폼·포커스까지 이해한 뒤에는 같은 동작을 재사용하는 구조와 연결의 수명을 읽을 수 있습니다.

각 장의 앞부분은 정의와 원리를 설명하는 본문입니다. 작은 코드를 줄마다 해설한 다음 그 개념이 실제로 작동하는 예제를 보여줍니다. 코드를 수정하는 연습은 장 끝에 접어 두었습니다. 본문을 읽는 동안 문제를 먼저 풀 필요는 없습니다.
